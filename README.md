# AR召喚 - WebARアプリケーション

大学イベント向けのWebAR体験コンテンツです。タッチ時間に応じて異なるオブジェクトを召喚できます。

## 概要

- ARマーカー（Hiro）を認識すると魔法陣が表示されます
- 画面をタッチする時間に応じて3種類のオブジェクトを召喚できます
- スマートフォンのブラウザで動作します（アプリインストール不要）

## 技術仕様

- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **ARライブラリ**: A-Frame v1.5.0 + AR.js v3.4.5
- **対応ブラウザ**: iOS Safari, Android Chrome（最新版）

## 使用方法

### 基本操作

1. **アクセス**: スマートフォンのブラウザで `index.html` にアクセス
2. **カメラ許可**: カメラの使用を許可する
3. **マーカー認識**: Hiroマーカーをカメラに向ける
4. **魔法陣表示**: 小さな魔法陣が浮遊しながら表示される
5. **オブジェクト召喚**: 画面をタッチしてオブジェクトを召喚

### タッチ操作による召喚システム

画面を指でタッチし、**タッチ時間の長さ**によって召喚されるオブジェクトが決まります：

- **短いタッチ（0-500ms）**: オブジェクトA
- **中くらいタッチ（500-1500ms）**: オブジェクトB  
- **長いタッチ（1500ms以上）**: オブジェクトC

### 操作のコツ

- **短時間召喚**: 画面を軽く「ポンッ」とタップ
- **中時間召喚**: 画面を0.5秒程度押し続ける
- **長時間召喚**: 画面を1.5秒以上しっかり押し続ける

## 召喚されるオブジェクト

現在3種類のオブジェクトが召喚可能です：

| タッチ時間 | オブジェクト | 説明 |
|-----------|------------|------|
| 0-500ms | オブジェクトA | 高速タッチで召喚される |
| 500-1500ms | オブジェクトB | 中速タッチで召喚される |
| 1500ms+ | オブジェクトC | 低速タッチで召喚される |

*注: オブジェクトD、Eは実装済みですが現在非表示設定です*

## デバッグ機能

開発・テスト用のデバッグ関数がブラウザコンソールで利用できます：

```javascript
// 基本テスト
testDebugObject()           // デバッグ用の形状を表示
checkStatus()              // システム状態確認

// オブジェクト召喚テスト
testSummon('model-a')      // オブジェクトAを直接召喚
testSummon('model-b')      // オブジェクトBを直接召喚
testSummon('model-c')      // オブジェクトCを直接召喚

// 隠しオブジェクトテスト
testSummon('model-d')      // オブジェクトD（非表示設定）
testSummon('model-e')      // オブジェクトE（非表示設定）

// フォールバック表示テスト
testFallback('model-a')    // 3Dモデル読み込み失敗時の代替表示

// 魔法陣テスト
testMagicCircle()          // 魔法陣表示状態確認
toggleMagicCircle()        // 魔法陣表示切り替え
```

## システム特徴

### 魔法陣システム
- **浮遊表示**: 魔法陣がマーカーから浮いて表示される
- **サイズ最適化**: 1.5×1.5の適切なサイズに調整済み
- **アニメーション**: 回転・浮遊・装飾リングのアニメーション

### オブジェクト表示
- **大きなサイズ**: 魔法陣とのバランスを考慮した1.5倍スケール
- **召喚アニメーション**: 0.2倍から1.5倍に拡大する迫力のアニメーション
- **フォールバック表示**: 3Dモデル読み込み失敗時の代替表示システム

### UI/UX
- **シンプルなデザイン**: 絵文字を削除したクリーンなインターフェース
- **直感的操作**: タッチ時間による分かりやすい操作方法
- **リアルタイムフィードバック**: タッチ中の視覚的フィードバック

## 動作環境

- **推奨環境**: HTTPS環境（カメラアクセスのため）
- **対応デバイス**: スマートフォン・タブレット
- **照明条件**: 明るい環境でのマーカー認識を推奨
